# 文件工具重复绘制与读取竞态修复

日期：2026-10-21。基线：`a76ad8d1fb619dea35eff2adbf4a242f99e5f203`。版本保持 3.0.4，本轮未部署生产环境。

## 图片拼接

- 移除重复的图片加载、绘制循环；每个输入文件只解码一次，保存解码图像，预览与导出复用同一绘图函数，每张图片每次渲染只绘制一次。
- 同批并行解码后保留选择顺序，多批按提交顺序入队。清空、卸载使旧任务失效，并释放对象地址、事件监听和定时器；解码失败或 15 秒超时不会阻塞其他成功图片。
- 读取中显示反馈并禁用缺图下载；初次读取尚未完成也可清空。预览失败提供错误和重试，绘图上下文不可用及空画布编码均明确失败。
- 下载复用已有 `encodeImageCanvas` 的 Blob、MIME 与真实文件头校验，避免 Data URL 下载兼容问题。编码期间换图、清空或修改参数会使旧导出失效；扩展名使用编码时的格式快照。

## 三款表格转换

涉及 CSV→Excel、Excel→CSV、Excel→JSON。

- 新增仅供这三款工具共用的 `Tools/Spreadsheet/useSpreadsheetRead.ts`，统一读取版本、取消、解析提交、卸载清理及错误反馈。
- 换文件、清空后旧读取和已经进入异步运行时加载的解析结果不能提交到页面，取消后的迟到错误也不再提示。
- 新文件开始读取时立即清除旧产物；读取中禁用下载、复制。读取或解析失败保留当前文件名称、显示重新上传提示，允许重选同一文件。
- CSV/XLSX 异步导出再次核对当前文件与工作簿，避免等待库加载时切换文件导致内容和名称错配。下载名仅去除最后一个扩展名，保留原名称中的其他句点。
