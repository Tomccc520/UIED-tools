# 3.0.4 主站主题色统一记录

日期：2026-10-20。检查基线：`31e0ccc0`。版本号保持 3.0.4。

## 本轮范围

- 网站原有品牌紫保持 `#6C54FF`，悬停色 `#5842CC`，浅背景 `#F8F7FF`，浅边框 `#DED7FF`。
- CSS 完整颜色变量、透明度和 Tailwind `brand` 语义类共用 RGB 通道；Element Plus 的主色、选中、滑杆与实心主按钮悬停同步主题。
- 公共搜索、推荐区、使用指南、页脚、首页、更新记录、关于与 404 页收口品牌色。
- 资讯、AI 工具目录、二维码、图标生成器、Favicon、图片转换、图片转 GIF、GIF/PDF/视频压缩和视频转 GIF 的普通操作统一主题。
- PDF 合并、分割、旋转、删除、加密、水印、页码、签名、文字提取、PDF/图片互转、文本与 Markdown 转 PDF 同步普通界面配色。
- 用户登录/中心、两款 JSON 页同步普通强调色。随机推荐页已使用主题变量，没有重复修改。

保留用户作品颜色、二维码黑白设置、PDF 签名/水印颜色、透明棋盘、代码语法与数据配色、运营配置，以及成功、危险、错误、警告、停用等状态色。39 个被修改 Vue 文件的业务脚本与基线内容完全一致。

## 独立待办

- 这是一批公共样式和常用页面的迁移；其他存量页面仍可能保留独立 Tailwind 调色类，后续应逐页判断语义后迁移，不能全局重定义 blue/purple 调色板。
- 图片格式转换独立入口 `/tools/image-to-webp` 的原有主标题使用 H2，没有 H1；本轮未混入结构改动。
- 资讯列表仍能展示有效来源，但浏览器记录到部分既有外部源失败：36氪 XML 解析错误、量子位 HTTP 403，以及 UIED/机器之心请求失败。应独立处理来源与网关，不属于本轮主题修改。
