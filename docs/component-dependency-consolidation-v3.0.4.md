# 组件复用与依赖收敛：首轮记录

日期：2026-10-21。代码基线：`7367488f`。版本保持 3.0.4。

## 已完成

- 新增公共 `FileUploadZone.vue`，统一原生文件选择、顺序、重复选择、拖拽高亮、禁用、忙碌反馈与键盘入口。业务格式/大小校验和处理生命周期留在各工具。
- Favicon、图片格式转换、图片合成 GIF 三个页面接入，删除重复的输入、选择按钮和拖拽处理。Favicon 拖入文件不再需要构造 DataTransfer 再写回文件输入。
- 既有 `VideoUploadZone.vue` 改为兼容包装，视频压缩与视频转 GIF 继续使用原有 select/drop 事件、选择器、处理和计费逻辑。
- 图片合成 GIF 在接入处拒绝非图片，并保留已有帧与预览。先补失败测试复现误清空，再完成修复；没有把图片校验塞入公共组件。
- 排行榜、随机工具、合同模板、OKR 共四个页面/组件及组件生成模板迁移到既有 Element Plus Icons。删除已无运行时引用的 `@heroicons/vue`，同步 npm、pnpm 锁文件，未新增第三方依赖。

## 验证结果

- 单元测试：65 个文件，645 项通过，含 11 项公共上传行为测试及非图片不破坏 GIF 结果的回归。
- TypeScript 和 `npm run build:check` 通过，`git diff --check` 通过。
- 公共组件覆盖选择顺序、单选、accept 不替业务过滤、同文件重选、取消选择、拖拽内外移动、禁用、busy 仍可追加，以及外部模式不重复触发。
- 实际浏览器：Favicon 的 Enter、Space 都能打开系统选择器；真实下载 PNG 签名与尺寸正确，为 16×16。
- 批量图片转换：ZIP 包含 01.png、02.png，独立核对 PNG 编码及 100×100、200×200 尺寸。
- 图片合成 GIF：分两批添加后仍为 01、02、03，独立解码下载 GIF，画布 100×100、3 帧、每帧 500ms，中心颜色按红、蓝、绿排列。
- 两款视频工具均通过兼容包装选择真实 MP4，并正常进入设置与预览区；本轮未重复做完整转码压力测试。
- 1440px、375px 检查五个上传入口与四个图标迁移页面；320px 检查五个上传入口，768px 检查图片合成 GIF 和视频压缩，均无横向溢出。

本地证据位于 `output/playwright/component-reuse-2026-10-21/`，按仓库规则不提交。回归初期本地 MySQL/Redis 容器停止导致站点配置和热榜报错；恢复已有容器后热榜接口返回 200 及真实数据，没有执行数据库补丁或导入。

## 后续候选与边界

- `vue-devui`、`@devui-design/icons`：本轮未发现运行时、全局样式或构建自动注册消费者；下一批可单独清理并做干净安装/构建回归。
- `html2pdf.js`：未发现当前调用，但仍有类型声明和分包条目，应成组检查清理并回归相关导出入口。`@toast-ui/editor`、`image-conversion` 也列为后续候选。
- 保留 PDF.js 渲染、pdf-lib 编辑、qpdf 加密，以及 CompressorJS JPG/WebP 和 UPNG PNG 编码等互补职责，不能只按同类名称删除。
- 重型文件处理、Worker 和异步加载边界保留。本轮没有首屏性能基准，不把删除依赖的安装目录体积当作网页加载节省量。
- 新组件尚未迁移所有 PDF、Element Upload 和其他上传场景；后续按实际事件与生命周期逐组接入，避免扩大通用组件职责。
