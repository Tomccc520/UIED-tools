# 计算与 PDF 编辑修复记录（2026-10-19）

修复基线：`b2c6b54ca874349a2dde358cf4f6a639ad01baac`。产品版本保持 `3.0.3`，本轮不部署生产环境。

## 修复范围

| 反馈 | 修改与验收重点 |
| --- | --- |
| 温度偏移公式错误 | 华氏、开氏、兰氏先正确转换到摄氏，再计算其他单位；完整校验有限数值。覆盖 32°F、212°F、−40°F、273.15K、0K、五单位往返。 |
| 中文数字大写数量级丢失 | 按四位分组拼接万、亿、万亿及跨组零；零返回“零”。保留最多 13 位非负整数范围，禁止小数和科学计数法被截断成整数。 |
| 两款房贷工具零利率 NaN | 统一计算函数；零利率直接均摊本金。覆盖两种还款方式、对比两侧均零/仅一侧零、有效期限和有限数值。真实输入控件清空输出 `null`，必须在乘法前验证原始金额/期限，避免被转换成零。 |
| 年龄累计月份重复减年 | 使用原始年份差 × 12 + 月份差，再判断是否满月。固定 2026-10-19 验证 70、0、11 个月。 |
| 一月星座错误 | 用含起止端点的月日区间匹配，明确跨年摩羯范围。按原日期表覆盖 1/19、1/20、1/25、1/31、2/18、2/19、12/21、12/22。日期按本地日历解析，生日当天全天剩余 0 天。 |
| PDF 旋转重排导出错误 | 以稳定的源页面 `id` 复制，保存前快照文件、顺序及旋转值；串行写入保证 C/A/B 顺序。 |
| PDF 删除旋转无法导出 | 使用 pdf-lib 的 `degrees(...)`，叠加源页面角度；保存前快照保留页并串行复制；禁止导出零页文档。 |
| PDF 预览重复旋转及重置不重绘 | 只由 PDF.js 渲染旋转，去掉 canvas CSS 旋转；重置清除增量并重绘，保留源页面角度。复用已加载文档，并用等待链和版本隔离快速旋转、清除及过期失败。 |

## 失败先行

- 中文数字旧实现：0 返回空串、100000 返回“壹拾”、1000000000000 返回“壹万”；原实现的 17 个用例中 14 个失败。
- 温度及房贷旧实现：32°F → −551.1111104°C、零利率等额本息为 NaN；初始 24 例中 23 例失败。
- 年龄旧实现：2020-12-15 累计 58 个月，2025-10-20 得到 −1 个月；一月星座及生日当天天数也失败，初始 21 例中 8 例失败。
- PDF 旧实现：初始 8 例全部失败，覆盖重排、保存快照、90/180/270 度、源旋转、重复预览旋转和重置。
- 独立复核还发现房贷 `null × 10000 → 0`；先改为真实控件行为再补清空测试，证实两页均失败后修复。
