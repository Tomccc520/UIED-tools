# 3.0.6 文件处理与接口回归

本轮从干净的 `47e2e3e3` 开始，重点检查四个文件工具和排行榜、视频下载两条接口链路。保持 3.0.6，仅修复并验证源码，不生成部署归档、不部署生产，也不更改数据库。

## 确认与修复

| 入口 | 原问题 | 当前行为 |
| --- | --- | --- |
| `/tools/json-to-excel` | 格式化经 `JSON.parse/stringify` 改写大整数、指数及长小数；嵌套对象和数组被 SheetJS 当成非单元格对象，导出丢内容 | 格式化复用无损 token 排版；无法安全表示的数值明确报错并保留输入，由用户自行加双引号作为文本；嵌套结构明确作为 JSON 文本写入单元格 |
| `/tools/json-to-excel` | 非对象行可生成空表；超限列被 XLSX 默认截断；等待加载库时修改、清空或离开仍可能下载旧任务 | 校验非空对象数组、有效字段及工作表行列上限；输入变化或卸载使旧任务失效，失败不提示成功 |
| `/tools/pdf-extract-text` | A 提取中重新上传 B，迟到的 A 可覆盖结果，下载名与内容不一致；缩略图也存在旧回调回写 | 提取与缩略图使用文件身份和请求版本，清空、换文件、离开均失效并销毁旧 PDF.js 任务；旧进度、提示及 finally 不影响新任务 |
| `/tools/pdf-to-images` | 转换每页时读取当前 DPI，处理中切换质量会让同一批次混用尺寸 | 启动时快照文件队列与 DPI；处理中禁用质量按钮，后续页面不读取可变参数 |
| `/tools/img-cut` | 多次读取乱序覆盖图片，清空后旧图片重新出现，旧打包完成后仍下载 | 读取、解码及 ZIP 打包均校验版本，换图、清空和卸载使旧回调失效；失败可重新选择 |
| `/tools/img-cut` | 同一 Canvas 连续绘制切片，透明区域叠上上一片像素 | 每片绘制前清空画布，保留透明和半透明像素；打包 URL 在下载启动后延迟释放 |
| 排行榜访问统计 | POST 成功前已写入去重时间，失败后十分钟内无法重试；sessionStorage 异常会阻止请求 | 成功才记录去重；并发共享在途请求，失败释放；存储异常使用内存去重，不阻止上报 |
| 视频压缩附件 | Gin 旧版本将中文文件名中的空格编码成 `+`，前端普通参数解析又会截断分号或引号 | Go 使用 `mime.FormatMediaType` 发送标准附件参数；前端识别 quoted-string、UTF-8 扩展参数和回退名称，保留空格、加号、分号与引号 |

JSON 转 Excel 遵循工作表的 15 位有效数字、数值范围、1048576 行（含表头）及 16384 列限制，并额外检查 JavaScript 数值转换是否改变十进制值。不能安全转换时停止导出，不擅自把 JSON 数值改为字符串。[Microsoft Excel 规格](https://support.microsoft.com/en-us/excel/excel-specifications-and-limits)给出了这些工作表与精度边界。

## 验证结果

- 主站 76 个测试文件、813 项单测通过；`build:check` 类型检查、生产构建及六个工具预渲染通过。
- 7 项预渲染与路由生成脚本回归通过；Go `admin/routers/common` 包通过，包含四种真实处理器附件名往返、MIME、文件内容及发送后清理验证。
- 新增失败回归先在旧实现复现，再验证修复。涵盖读取乱序、清空、卸载、失败重试、DPI 变化、统计去重、存储异常及文件名编码。
- 浏览器实际下载 XLSX 后用真实 SheetJS 重读：`9007199254740993` 文本、嵌套对象及数组完整保留；非法长数值不下载并显示错误。
- 6×6 RGBA 图片实际导出九张 2×2 PNG。第 2/5/8 张 alpha 为 0；第 3/6/9 张为蓝色、alpha 为 128，没有红色叠入。
- 144×72 点的双页 PDF 以 150 DPI 实际转换，两张 PNG 均为 300×150；提取并下载的 TXT 同时包含 `PAGE A` 和 `PAGE B`。
- 本地真实视频接口以“测试 视频;v2.mp4”上传，响应保留完整附件名，MIME 为 `video/mp4`，文件头含 MP4 `ftyp`。本样例未缩小体积，服务按既有规则返回原视频，未误判为新压缩产物。
- 四个页面在 320、375、768、1440px 检查通过，没有横向溢出，每页一个 H1。

主要构建、测试和真实产物证据位于忽略目录 `output/bug-audit-3.0.6-20261025/`；API 隔离回归日志位于 `output/bug-audit-3.0.6/api/`，PDF 失败基线位于 `output/bug-audit-2026-10-25/`。这些本地结果不代表生产已部署，也不代表全部工具和后台功能已完成全量审计。
