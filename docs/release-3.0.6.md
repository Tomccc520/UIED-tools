# UIED-Tools 3.0.6 待发布说明

当前阶段为代码修复与验证，版本号统一为 **3.0.6**。本轮不生成部署包、不执行线上部署，等待明确打包指令后再准备当前版本的部署说明、发布校验和宝塔命令。已有 3.0.5 部署包与文档保留作为历史发布记录。

本轮修复范围：

- 工具页首个 HTML 补充预渲染正文、独立标题描述及自身 canonical，覆盖二维码、JSON 格式化、图片压缩、GIF 压缩、PDF 压缩、视频压缩六个入口。
- 加载后的页面继续使用工具独立 SEO；后台接口失败或仍保留全站通用配置时，不覆盖路由专属兜底文案。
- 站点配置读取校验业务码及有效登录开关，共享在途请求，瞬态错误最多重试一次，并区分网络、超时及服务异常提示。
- 未知路径继续返回真实 HTTP 404 和 noindex，回归有效深链接及历史地址跳转。
- 排行榜配置回调和番茄钟卸载不再覆盖新页面标题，保留后台独立 SEO 与分享标题的一致性。
- 精确兼容四款压缩工具的历史默认描述，避免旧文件限制、GIF 批量能力和视频分辨率承诺继续进入描述、SEO 或 GEO；保留后台独立自定义文案。

## 本地验收结果（2026-10-25）

- 主站 72 个测试文件、765 项单测通过；主站 `build:check`（含类型检查与六页真实预渲染）通过。本次只修改主站，后台类型检查和 Go 默认时间线、公共配置、网站设置三个包测试已在此前同版本验证通过。
- 16 项预渲染、路由生成、发布来源及发布恢复回归通过。新增标题竞争测试在修复前 3 项均失败，修复后通过；历史压缩描述测试在修复前 4 项均失败，修复后通过。
- 使用现有 Nginx 1.27 容器加载正式路由扩展配置，通过 curl 验证六页及各自尾斜杠/查询地址，共 12 个工具响应均为 HTTP 200，包含工具专属正文、唯一 H1、输入区和自身 canonical。未知地址、`/404`、快照内部路径三项均返回 HTTP 404 与 noindex，共 15 项检查通过。
- 后台 API 返回 502 时，二维码与 JSON 页面加载完成后仍保留专属标题、描述与自身 canonical。恢复本地固定配置后，二维码生成及 JSON 格式化/压缩正常；大整数、长小数与 `1e400` 保持原值。
- 前轮二维码和 JSON、此次新增四个压缩入口均已检查 320、375、768、1440px，未出现横向溢出。真实 API 带有旧默认描述时，四个压缩页面加载后的描述已匹配当前能力文案，后台独立标题继续保留。前轮证据位于 `output/seo-3.0.6/`，本轮构建、测试、原始 HTTP 与视口记录位于忽略目录 `output/seo-3.0.6-expansion/`。

静态首个 HTML 当前覆盖上述六页，其他历史工具没有在本轮全部预渲染。上线验收仍需分别检查原始 HTTP 响应与浏览器 DOM；本地通过不代表生产环境已经部署，也不代表搜索引擎已经收录。

当前未生成 3.0.6 部署归档，未执行线上部署。后续收到明确打包指令时，需连同生成的工具快照和 Nginx 白名单一起发布。
