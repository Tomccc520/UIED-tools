# UIED-Tools 3.0.6 待发布说明

当前阶段为代码修复与验证，版本号统一为 **3.0.6**。本轮不生成部署包、不执行线上部署，等待明确打包指令后再准备当前版本的部署说明、发布校验和宝塔命令。已有 3.0.5 部署包与文档保留作为历史发布记录。

本轮修复范围：

- 工具页首个 HTML 补充预渲染正文、独立标题描述及自身 canonical，优先验证二维码和 JSON 格式化页面。
- 加载后的页面继续使用工具独立 SEO；后台接口失败或仍保留全站通用配置时，不覆盖路由专属兜底文案。
- 站点配置读取校验业务码及有效登录开关，共享在途请求，瞬态错误最多重试一次，并区分网络、超时及服务异常提示。
- 未知路径继续返回真实 HTTP 404 和 noindex，回归有效深链接及历史地址跳转。

## 本地验收结果（2026-10-25）

- 主站 71 个测试文件、744 项单测通过；主站 `build:check`（含类型检查与真实页面预渲染）、后台类型检查通过。
- 16 项预渲染、路由生成、发布来源及发布恢复回归通过；Go 默认时间线、公共配置、网站设置三个包测试通过。
- 使用现有 Nginx 1.27 容器加载正式路由扩展配置，通过 curl 验证两页和尾斜杠/查询地址均返回工具专属 HTML；正文分别包含 1119、1217 字符、H1 和输入区。未知地址、`/404`、快照内部路径均返回 HTTP 404 与 noindex。
- 后台 API 返回 502 时，二维码与 JSON 页面加载完成后仍保留专属标题、描述与自身 canonical。恢复本地固定配置后，二维码生成及 JSON 格式化/压缩正常；大整数、长小数与 `1e400` 保持原值。
- 两页在 320、375、768、1440px 的真实浏览器回归均未出现横向溢出。证据位于忽略目录 `output/seo-3.0.6/`。

静态首个 HTML 当前覆盖二维码和 JSON 格式化这两页，其他历史工具没有在本轮全部预渲染。上线验收仍需分别检查原始 HTTP 响应与浏览器 DOM；本地通过不代表生产环境已经部署，也不代表搜索引擎已经收录。

当前未生成 3.0.6 部署归档，未执行线上部署。后续收到明确打包指令时，需连同生成的工具快照和 Nginx 白名单一起发布。
