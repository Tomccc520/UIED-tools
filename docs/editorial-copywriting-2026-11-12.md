## 如何维护

前后端共用 [copywriting_library.json](../backend/likeadmin-go/server/admin/service/common/copywriting_library.json)。增补或修正文案时编辑对应工具的数组，保持 `id` 唯一、正文不重复，并更新 `updatedAt`（北京时间 `YYYY-MM-DD`）。同一条文案的常规修订可保留原 ID。

- `kfc`：中文 `text` 与英文 `english` 成对维护。仅收录原创玩梗内容，不写未经验证的价格、优惠或活动。
- `daily-poem`：完整正文用 `\n` 分行，保留 `title`、`author`、`dynasty`、`from`；不同版本有异文时注明所用版本。核对出处可参考[《全唐诗》](https://zh.wikisource.org/wiki/%E5%85%A8%E5%94%90%E8%A9%A9)、[《樊川文集》外集《山行》](https://zh.wikisource.org/wiki/%E5%B1%B1%E8%A1%8C_%28%E6%9D%9C%E7%89%A7%29)和[《东坡诗集注》所收《赠刘景文》](https://zh.wikisource.org/wiki/%E8%B4%88%E5%8A%89%E6%99%AF%E6%96%87)。
- `dog-diary`：使用原创虚构段子，不引用真实私聊和可识别个人信息。
- `moments`：保留场景 `topic`，每个场景至少两条，方便用户继续换内容。

发布新版 Go 服务后，四页在下次打开时从 `GET /api/common/copywriting/library/:kind` 同步站内内容，接口成功响应可缓存 5 分钟；重建前端也会刷新随页面分发的内置库。页面先用内置库出首屏，接口报错或超时保持可用。当天精选由北京时间日序决定，换内容在已加载的库内轮换；每天换精选不等于每天自动创作新内容。

四个旧随机入口继续兼容原响应结构，改由站内库返回 `source=editorial`。旧的 KFC 翻译入口命中站内原句时也直接返回配套英文；其他翻译和文案工具沿用原有契约。四页不再加载外部按钮动画。

## 验证

- Go 文案服务与真实路由测试：已验证四个站内读取入口无需登录、不请求第三方，旧入口保留字段，未知类型会返回业务错误。
- 浏览器服务与页面测试：已覆盖北京时间换日、同一场景内轮换、复制原文与出处、英文配对、超时和迟到的同步响应。
- 全量单测 81 个文件、889 项通过；TypeScript、生产构建与工具路由检查通过。Go 测试使用独立的临时 MySQL/Redis 实例。
- 生产构建通过本地 Go 网关联调：四页在 320/375/768/1440px 均只有一个 H1、无横向溢出，回车可换内容；实际剪贴板保留完整诗词与出处。每页只读取一次站内库，切换、英文和场景筛选不额外请求接口。模拟库接口 HTTP 503 时，四页仍可显示和切换。
