# 图片压缩移动端适配（2026-10-19）

基准：`9b4c11e0`，版本 `3.0.3`。本次首先完成 `/tools/image-compress` 的窄屏工作流，并修复共用头部的平板导航问题；不是全站移动端页面逐一验收。未提交、推送、升级版本或部署。

## 实现选择

继续共用一个 Vue 页面、一组参数、文件队列和压缩逻辑，通过工作区实际宽度调整展示，不单独维护移动路由或复制一套页面。移动端额外保存的只有参数面板的展开状态。视口较宽但被左右栏挤窄时，也会使用紧凑布局。

## 已优化

- 窄屏压缩参数默认收起，显示质量、JPG / WebP 尺寸策略与 PNG 模式摘要；可通过触摸、Enter 或空格展开，参数设置不会因收起而丢失。宽工作区直接显示同一组控件。
- 手机原图与结果并排预览，按容器宽度缩放；放大预览仍可打开并通过关闭操作恢复。
- 手机上传区缩小留白与图标，使用“点击选择图片”的文案；320×640 下完整上传按钮及选择提示在首屏可见。
- 文件名支持两行换行；移除按钮为 44×44px，单张下载至少 72×44px，打包下载为全宽且至少 48px 高。
- 扩大滑块触控区域，PNG 颜色下拉框至少 44px 高，字号 16px。辅助说明保留至少 12px 字号。
- 批量列表保留有限高度，但取消窄屏的滚动隔离；到达列表边缘后可继续滚动页面。帮助与 FAQ 保留原生展开、键盘焦点及纵向步骤。

修改前，375px 下选择两张图片时预览区起点约为 897px、下载摘要起点约为 1969px；问题主要是操作距离，而非横向溢出。折叠参数和缩小预览后，长文件名与失败提示仍能完整参与布局，不依赖覆盖页面的固定底栏。

## 平板导航修复

`Header.vue` 原先以 768px 判断是否使用抽屉，固定侧栏实际从 992px 才显示，因此 769–991px 点击菜单可能无法打开导航。

现将导航模式独立统一为：小于 992px 使用抽屉，992px 起使用固定侧栏。跨断点关闭旧抽屉；按钮文案及 `aria-expanded` 从真实导航状态推导。桌面独立折叠偏好保留，未改其他内容布局。

实际内置浏览器验证 768 / 820 / 991px 打开和 Esc 关闭抽屉；关闭及跨 992px 后，遮罩与 body 滚动锁定均释放，返回平板不恢复旧遮罩。992px 固定侧栏可正常折叠与展开。
