- 先补失败用例：Logo 读取竞态、WAV 首尾与短缓冲、资讯分类/竞态/失败及 RSS 正文超时、后台 0 分与保存门禁均在原代码上复现失败。
- 主站：69 个测试文件、682 项通过，包含新增/扩展的 Logo 16 项、WAV 6 项、资讯页面 7 项和 RSS 服务 6 项。
- 后台：`node --test scripts/admin-config-safety.test.mjs scripts/admin-navigation.test.mjs scripts/tool-catalog-editor.test.mjs` 共 19 项通过，其中 7 项为本轮配置安全回归。
- 主站 `npm run build:check`（含 TypeScript）通过；后台 `npm run type-check`、`COPY_TO_FRONTEND=0 npm run build` 通过。后台构建没有覆盖发布目录。
- `npm run check:tools`、`git diff --check` 通过。
- 真实浏览器：初次加载期间键盘选择 IT之家、连续切换少数派再回 IT之家，显示当前来源且 schema 有 50 条；36氪来源解析失败时显示“资讯加载失败，请重试”，没有同时显示空状态。键盘重试后切回可用来源恢复。
- 视频：上传含 1 秒 AAC 音轨的 MP4，实际提取并下载 WAV；Python 标准 `wave` 独立读取为单声道、48kHz、16 位、48,000 帧，首尾样本非额外补零。另用确定的双声道测试缓冲验证全部 100 帧及 200 个交错样本，文件头正确、首尾值保留。
- Logo：实际上传 100×100 图片生成规范，换成 200×200 图片再次生成后，预览的自然尺寸确为 200×200；重置后品牌名称和 Logo 预览均清空。异步乱序、卸载及失败分支由可控 FileReader 回归覆盖。
- 资讯、视频提取结果覆盖 320/375/768/1440px，Logo 预览覆盖 375px，均无横向溢出。记录同时保存请求尺寸和实际视口尺寸。

本地证据位于 `output/bug-audit-2026-10-21/` 及 `output/bug-audit-*.log`，按仓库规则不提交。临时定时器诊断日志和重复下载已清理；保留可复核的 WAV、视频夹具、截图与 JSON 记录。
