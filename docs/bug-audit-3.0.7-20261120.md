# UIED-Tools 3.0.7 排查记录

2026-11-20，从 GitHub 基线 `3b7b9299` 开始，在本地检查 Vue 主站、管理端、Go API 和宝塔发布流程。

## 已复现和修复

| 位置 | 原有问题 | 验收结果 |
| --- | --- | --- |
| 图片转 PDF | 合并横竖图时，页面尺寸和图片比例可能错误 | 独立读取导出的 PDF，核对逐页尺寸、顺序和 A4 居中排版 |
| 图片合成 GIF | 改参数仍可下载旧文件，画质滑杆方向相反，编码异常后可能持续等待 | 浏览器导出真实 GIF；单测覆盖旧结果失效、错误和超时后重试 |
| 文案与翻译 | 上游返回 HTTP 200 时可能把错误提示当译文，部分日记响应漏读正文，旧页面请求可能一直等待 | 回归覆盖业务错误、异常响应和超时降级；抽查随机表情包两次均得到可解码的 JPEG |
| 后台表格 | 素材、文章、部门、岗位等 17 处表格误把列传入默认插槽 | 修复列插槽，在本地浏览器用样本数据确认显示，并对所有后台 Vue 模板增加列声明检查 |
| 后台配置 | 榜单请求返回时可能把随后编辑的草稿标为已保存，本地存储有实际无效的停用操作 | 测试覆盖保存中的再次编辑、唯一存储引擎的服务端校验和响应数据隔离 |
| 更新记录 | 默认版本迁移可能改写运营文案，保存后还会丢失自定义字段 | 后台保存、再次读取和公共接口均保留自定义版本、分组扩展信息 |
| 发布流程 | 旧版本构建产物可以进入新版本的部署包 | 模拟版本错配时校验失败；使用 3.0.7 主站与后台构建时校验通过 |

## 验证范围

- 主站 85 个测试文件、914 项测试通过。后台 340 项测试通过。两端均通过 TypeScript 检查与生产构建，Go 全仓测试通过。
- Chrome 实际下载覆盖图片压缩、格式转换、图片转 PDF 和 GIF、视频压缩，以及 PDF 压缩、合并、分割、加密、重排旋转、删除和水印。PDF 的页序、旋转、密码和水印另用独立阅读工具验证。
- 搜索的点击和键盘导航、SQL、JSON 转义、Unicode、时间戳、进制和计算工具完成浏览器回归。更新记录及后台登录页在 320、375、768、1440 像素宽度均能看到当前版本。
- 在临时 Nginx 中加载项目的部署配置，对 321 个可索引页面检查原始 HTML 的独立元数据。sitemap 中 321 条地址全部返回 200。另验证未知路径返回 404 与 `noindex`，旧链接及 www 域名永久跳转并保留参数。

生产管理员权限、真实生产数据写入及 CDN 缓存需要上线后单独验收。构建仍提示部分依赖分块较大、Browserslist 数据较旧和 Sass 旧接口弃用。

## 2026-11-25 发布前复查

- PDF 压缩改为高清、推荐、强力三档，默认按推荐档优化内嵌图片。实际下载的图文 PDF 从 2.85 MB 压到 746 KB，独立阅读器仍可读取文字、链接、表单值和原页面尺寸。同一份 8 页模拟扫描件从 23.1 MB 压到 4.41 MB。强力档的对应产物为 394 KB 和 1.24 MB。
- 增加更新时间线的空数组、无效条目和高精度扩展字段回归。空或无效时间线恢复完整历史，公共配置 API 保留扩展字段的原始数值。
