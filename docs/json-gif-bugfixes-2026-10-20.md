# JSON 数字保真与图片转 GIF 帧序修复

日期：2026-10-20。基线：`c73996e5b7ec92470237ee63c3cedec6d6443030`，版本仍为 3.0.4。

## 修改

- 两处 JSON 工具共用 `src/utils/losslessJson.ts`。先严格校验 JSON，再仅调整 token 间的空白，不经过 `Number`、`JSON.parse` 或 `JSON.stringify`。大整数、负数、长小数、指数、负零、字符串转义、重复键和键顺序均保留原文。无效输入显示语法位置并保留输入；独立结果区清理旧结果，避免将旧数据误认为本次结果。
- 图片转 GIF 先按选择顺序预留队列位置，再并行解码，跨批次保持顺序。画布取第一张成功图片的尺寸。坏图或 30 秒解码超时会提示并跳过；清空与卸载释放 URL、取消回调，迟到结果不能重新入队。读取期间不能预览、排序或移除单帧，可以清空取消；编码期间不能继续上传。
- 未更换 GIF 编码器、未调整页面视觉、未增加依赖。
