# 后台导航配置与工作台优化：2026-10-26

基线 `dd1baae9`，版本保持 **3.0.6**。继续处理工作台和网站设置的日常操作，未制作部署包、执行生产部署、修改数据库、调整计费或新增依赖。

## 操作变化

- 顶部与搜索按“顶栏链接 / 搜索推荐 / AI 工具页”三项切换，不再同时铺开所有链接。
- 前台菜单保留品牌文案、推荐链接、一级菜单、底部入口四个常用分组，菜单样式与 AI 独立左栏集中在高级维护区。
- 页脚改为“快捷入口 / 友情链接 / 官方媒体 / 文案与版权”四项。快捷入口与友情链接可以选择分组、编辑标题、添加与排序链接、调整分组顺序。原始 JSON 仍可在高级区域查看与修复。
- 链接与分组移除后可以撤销；后续编辑会使旧撤销失效。链接撤销按分组上下文隔离，切换或删除分组不会把上一组链接恢复到当前组；普通编辑不重挂载输入框。
- 三页使用统一配置编辑控制器。只保存本次变化字段，加载失败禁止保存，保存失败保留草稿，隐藏字段校验失败定位对应分组。只读账号可浏览分组但不能编辑。
- 工作台趋势默认收起，有访问数据并展开时才加载图表。图表八秒超时或失败给出重试；统计十二秒超时给出失败提示。缓存工作台五分钟内复用统计，手动刷新仍可用，失活后的迟到请求不能覆盖新结果。

## 配置契约

`GET /api/setting/website/detail` 对顶部、侧栏、页脚涉及的 **14 个已存数组字段**返回原始字符串，便于识别和修复损坏 JSON；未配置字段继续展示项目默认值。其余站点配置读取逻辑不变。

保存接口、权限 key、数据库结构及主站公共配置接口均未变更。三页发送字段 PATCH，不将未修改的异常原文、默认值或其他页面配置附带写回。主站原有“空自定义列表回退默认入口”行为仍保留，页面文案已说明；删除最后一项不代表隐藏整块入口。

有效配置保留组和链接中的扩展字段。对于会被 JavaScript 数值转换改值的大整数、长小数、溢出或下溢指数，可视编辑明确报错并保留原文，不自动改成字符串或舍入；其他未修改字段仍可独立保存。安全的等值指数写法与数字字符串不受限制。

没有新增菜单、权限、API endpoint 或数据库补丁。没有写入本地真实站点配置或生产配置。
