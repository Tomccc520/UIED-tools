## 同日后续排查

- 公共工具标题不再读取共享的上一页详情，而是按当前完整路由匹配目录。旧页面请求迟到或快速切换时，不会把旧工具标题与简介写到新页面；同路径的不同查询参数入口也能分别匹配。
- 宝塔升级脚本会备份托管的 Nginx 配置，先检查原配置，在 API 健康后安装新路由配置、校验并 reload。静态文件复制、权限设置、API 启动或配置加载失败都会进入恢复；恢复旧版本后再次检查 API 健康。首次部署没有历史 API 时明确报错，不宣称已完整回滚。
- 图片压缩修复同名文件 ZIP 覆盖、追加文件漏包、结果状态未更新、打包时修改队列的竞态与损坏图片无持久错误等问题。独立下载和 ZIP 使用相同的唯一名称；PNG 100% 质量使用无损编码。
- PDF 压缩校验后才加入业务队列，避免非法文件残留与正常上传误报重复；合并页补齐追加入口；分割范围完整校验，不再接受 `1abc`、小数或静默修正越界页码。预览与清除使用任务失效保护。
- 视频压缩在扣次检查前锁定任务，取消、换文件、兼容重试和迟到响应均受同一生命周期保护。专业 H.264 模式允许浏览器无法预览但服务端能解码的输入；兼容重试保留音频选项，下载前后校验结果快照，防止换文件后下载错误内容。

现有能力边界：PDF 压缩采用页面光栅化，压缩产物可能失去文字检索及交互元素，页面 FAQ 已说明；本轮修复不会把该策略变成无损压缩。视频已验证小型真实文件，尚未完成 500MB 长视频压力测试。功能回归通过不等于所有格式、所有浏览器和大文件场景均已覆盖。
