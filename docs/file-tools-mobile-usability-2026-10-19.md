# 文件工具手机操作适配验收

日期：2026-10-19。沿用已确认的图片压缩手机交互。本轮只完成下列四页的下一批适配，不代表全站或手机真机验收已完成。

## 范围与行为

| 页面 | 手机操作 | 桌面行为 |
| --- | --- | --- |
| `/tools/gif-compress` | 参数摘要与展开、原图/结果单张大图切换、固定压缩/下载/取消入口 | 保留双图、完整参数及行内操作 |
| `/tools/video/gif` | 截取起止时间常显，其他参数按需展开；原视频/GIF大预览切换；固定生成/下载/取消入口 | 保留完整工作区 |
| `/tools/video/compress` | 参数默认折叠，原视频/压缩后大预览切换；固定开始/重新压缩/下载入口 | 保留参数、视频和结果对比 |
| `/tools/pdf-compress` | 独立文件卡片，参数与高级设置折叠，固定批量压缩/下载；全屏单页预览与翻页 | 保留展开参数、行内批量操作及 iframe 预览 |

操作栏由 `src/components/Common/MobileToolActions.vue` 复用。仅在视口不超过 640px 时渲染，支持底部安全区域、状态播报、键盘焦点与取消。离开工具页移除操作栏及其页面底部留白。

## 本轮同时发现并修复

- 手机浏览器没有内置 PDF 查看器时，iframe 预览会灰屏。手机改为 PDF.js 直接读取 File/Blob 绘制单页 canvas，支持翻页、原始/压缩切换、加载错误重试和 30 秒超时。关闭、换源、卸载会清理任务，防止迟到的结果覆盖当前预览。
- 视频参数变更后，重新压缩在授权阶段取消或被拒绝，不再把旧结果误标为当前参数的可下载结果；成功生成新结果后才清除变更状态。
- GIF 修改参数后撤销旧结果，透明 GIF 安全回退准确显示“下载原图”。PDF 体积回退显示“保留原文件”。
- 手机 PDF 隐藏重复的行内打包按钮；光栅化导致文字不可选中/搜索的说明始终位于参数折叠区外。

## 实际浏览器验收

在本地 `http://localhost:5179` 使用真实浏览器视口 320、375、768、1440px 检查上传后的布局与断点，未发现横向溢出。375px 跑通四页实际文件处理与下载；320px 检查参数、预览及卡片空间；768/1440px 确认没有手机固定栏且桌面控件保留。

- GIF：不透明测试动画 32.84KB → 8.44KB；下载后独立解析为 GIF89a、4 帧、总时长 900ms。透明动画准确回退为原文件并显示限制说明。
- 视频转 GIF：320×180、2 秒视频生成 GIF；独立解析下载文件为 GIF89a、20 帧、总时长 2000ms。另检查修改起点和高级参数展开、原视频/结果切换。
- 视频压缩：实际专业模式输出 MP4；ffprobe 核对 H.264、320×180、2 秒、28156 字节。参数切换后底栏显示重新压缩与旧结果说明。
- PDF：两份文档批量处理并 ZIP 下载，独立解析压缩文档仍为 2 页，回退原文档仍为 3 页。图像较多的样本 1.60MB → 164.71KB；已较小的文档保留原文件。
- PDF 手机预览：canvas 实际非零绘制并显示 PAGE B TOP，下一页/上一页、原始/压缩切换正常；375/320px 对话框占满视口，打开时隐藏固定栏，关闭后恢复。
- SPA 返回首页后确认操作栏消失、body 底部留白恢复为 0。

截图和测试产物保存在 `output/playwright/file-tools-mobile-2026-10-19/`，包括手机结果页、PDF 实际渲染预览、GIF/MP4/ZIP 下载文件及构建/测试日志。
