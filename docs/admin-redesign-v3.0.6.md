# 后台重构记录：3.0.6

本轮将公共框架和网站配置、工具管理作为第一批落地范围。版本保持 3.0.6；这是开发工作区修改，没有执行部署打包或数据库变更。

## 已实现

| 范围 | 操作变化 |
| --- | --- |
| 工作台 | 常用任务按内容维护、网站配置、运营数据分组，入口只取账号已有权限。 |
| 配置导航 | 将隐藏的入口选择改为可见的用途分组，区分首页内容、广告推荐、前台品牌、后台品牌和单工具 SEO。 |
| 页面标题 | 网站配置页使用公共标题组件，统一标题、说明和辅助操作的排列。 |
| 保存反馈 | 共享保存条区分加载、草稿、保存、失败和成功；加载失败禁止提交默认配置。 |
| 工具管理 | 抽屉“保存工具并生效”完成真实持久化；“应用到列表”保留批量编辑流程。有其他草稿时提示先处理，避免连带发布。 |
| 首页内容 | 每日学习与更新记录统一为底部一个保存入口；只 PATCH 本页字段。保存后的刷新失败可单独重试。 |
| 全站 SEO | 保存成功后使用提交快照建立基线，去掉重复读取导致的误报与覆盖。 |
| 菜单编辑 | 高级配置可明确展开，品牌标识代码按需显示；菜单字段二列排列，排序按钮在边界禁用。 |
| 公共样式 | 品牌色读取主题变量，补齐 Arco 实际使用的 RGB 通道，按钮、链接与导航统一品牌紫；成功和错误保留各自颜色。修复全局 SCSS 中不生效的 `:deep()` 选择器；去掉配置区固定高度和嵌套滚动。 |

没有新增运行依赖，没有改变权限、工具路由或后端 API 契约。已有配置字段和扩展数据继续保留。

## 验证边界

隔离函数回归使用真实源码和可控网络边界，覆盖权限、加载失败、失败留稿、保存重试、连续保存慢刷新、批量草稿、字段补丁与基线。浏览器组件验收使用样例菜单和拦截接口，不代表真实账号权限或数据库持久化已验收。

正式后台当前需要用户完成图形验证码登录。登录后的真实“读取 → 修改 → 保存 → 回读 → 前台生效”仍需单独验收，不能用样例数据测试替代。
